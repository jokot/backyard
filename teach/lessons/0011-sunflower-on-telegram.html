Lesson 11 of the Stage 2 build

The same door, a second time

Peashooter got its Telegram door in Lesson 5. Sunflower gets the same door now — same gateway, same two setup paths, same profile-scoped isolation once it's wired up.

What's already known

Knowledge

The gateway mechanism itself doesn't change per profile — see the Gateway glossary entry from Lesson 5 if you need a refresher. What changes is which profile is active when you run setup: hermes gateway setup attaches the new bot to whichever profile hermes profile use last selected. Get that wrong and Sunflower's Telegram bot ends up talking to Peashooter's SOUL.md instead of its own.

Known failure mode — don't re-debug it

Lesson 5's Automatic setup failed in Telegram Web with no response from the "Create a bot" button — a Telegram-side issue with that in-app bot-creation feature, not a Hermes bug. Full details in learning record 0006. If Automatic fails the same way again, don't spend time re-debugging it — go straight to Manual BotFather below.

Do this now

Skill — hands on

1. Make Sunflower the active profile, then run setup:

hermes profile use sunflower
hermes gateway setup

Pick Telegram. Try Automatic ([1]) first — scan the QR code with your phone's Telegram app and confirm. If it errors with no response, switch to Manual instead: message @BotFather, run /newbot, pick a name and a globally-unique ...bot-suffixed username (different from Peashooter's bot username), and paste the returned token into the manual prompt.

2. Install it as a standing background service:

hermes gateway install

3. Confirm it's running:

hermes gateway status

Should show Sunflower's gateway as running, alongside Peashooter's — two separate bots, two separate profiles, both live at once.

Why must hermes profile use sunflower run before hermes gateway setup, not after?

Right — get the active profile wrong and the new Telegram bot ends up wired to the wrong SOUL.md entirely.

Not the mechanism — nothing about token caching depends on load order here.

Not required — a bot's username is whatever you pick with BotFather, unrelated to the Hermes profile name.
