Lesson 5 of the Peashooter build

Reachable somewhere other than a terminal

Peashooter has a domain, a voice, and memory. Now it needs a door in from outside your terminal — the same door Zain's specialists use.

What the gateway is

Knowledge Gateway is Hermes's messaging bridge. Once set up for a profile, messages sent to that platform reach the profile's agent loop directly — same SOUL.md, same memory, same model, just a different door in. Telegram is one of several platforms it supports (Discord, WhatsApp, Slack, Signal too); Stage 1 only wires up Telegram.

Two ways to get a bot token

Checking hermes gateway setup's actual code (not just --help, per the practice this build settled into after Lesson 2) turned up two paths it offers for Telegram:

  • Automatic — scan a QR code, confirm in your Telegram app, done. Under the hood this uses Telegram's own bot-creation mechanism, brokered one-time through a Nous-hosted service, just to skip manually copy-pasting a token. You end up with the same kind of token either way — a real, user-owned bot, saved locally.
  • Manual — message @BotFather in Telegram yourself, get a token, paste it in. No third-party broker call at all, a couple more manual steps.

This build is using Automatic — worth knowing Manual exists as a fallback if you ever want zero third-party involvement in setup.

Correction — Automatic failed in Telegram Web

On the real attempt, Automatic's "Create a bot" button errored with no response, visible in the browser's dev console against the newbot?manager=NousHostedHermesBot… call — a Telegram-side failure (that in-app bot-creation feature not working in the Telegram Web client), not a Hermes bug. Switched to Manual BotFather instead: message @BotFather, run /newbot, pick a name and a globally-unique …bot-suffixed username, paste the returned token into hermes gateway setup's manual prompt. Worked cleanly.

Do this now

Skill — hands on

1. Make Peashooter the active profile, then run setup:

hermes profile use peashooter
hermes gateway setup

Pick Telegram, then choice [1] for Automatic. It shows a QR code — scan it with your phone's Telegram app and confirm. The token gets saved to Peashooter's config automatically; you shouldn't need to touch it.

2. Install it as a standing background service (so it survives after you close this terminal, and restarts on login):

hermes gateway install

3. Confirm it's actually running:

hermes gateway status

Should show Peashooter's gateway as running, not stopped or errored.

Why does the Automatic path still count as "you own the bot," not "Nous owns it"?

Right — the broker call happens only during setup, to create the bot and hand you its token. Ongoing traffic runs directly between Telegram and your machine, same as the manual path.

Not the mechanism — nothing about the token's lifetime is different between the two paths.

The whole point of Automatic is skipping BotFather entirely — that's the Manual path.
